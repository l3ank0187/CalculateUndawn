# CalculateUndawn

เครื่องคำนวณต้นทุนคราฟของในเกม **Undawn** — ใส่ราคาและจำนวนวัตถุดิบ แล้วคำนวณราคารวม (รวมภาษี 8%) ให้อัตโนมัติ

## วัตถุดิบที่รองรับ

- แฟลกซ์สีขาว
- หนังสัตว์ชั้นดี
- เส้นใยแฟลกซ์สีขาว
- เขาสัตว์

## วิธีใช้

1. ใส่ **ราคาต่อชิ้น** และ **จำนวนชิ้น** ของวัตถุดิบแต่ละอย่าง
2. ระบบจะคำนวณราคารวมแต่ละรายการ + ผลรวมทั้งหมด (รวมภาษี 8%) ให้อัตโนมัติ

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## Tech Stack

- HTML / CSS / JavaScript (Vanilla)
- ธีมสีดำ
